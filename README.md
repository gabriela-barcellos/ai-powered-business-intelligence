# AI-Powered Business Intelligence

An interactive Business Intelligence dashboard built with Python and Streamlit to analyze sales performance, product contribution, customer behavior, and retention using the UCI Online Retail dataset.

## Features

- **Executive Overview:** Key performance indicators for revenue, invoices, and customers.
- **Sales Analytics:** Monthly revenue and invoice trends.
- **Product Analytics:** Top products ranked by revenue and quantity.
- **Customer Analytics:** Customer revenue and purchase-frequency rankings.
- **Retention Analysis:** Monthly active customers and next-month retention.
- **AI Business Analyst:** Ask questions about dashboard data using a locally running Ollama model.

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Requests
- OpenPyXL
- Ollama (`llama3.2:3b`)

## Dataset

This project uses the [UCI Online Retail dataset](https://archive.ics.uci.edu/dataset/352/online+retail).

The original dataset is not included in this repository. Download it from the official source and place `Online Retail.xlsx` in `data/raw/`.

The dashboard also uses processed CSV files stored in `data/processed/`. These files are generated by the project's data preparation and analysis scripts.

## Installation

### 1. Clone the repository

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/ai-powered-business-intelligence.git
cd ai-powered-business-intelligence
```

### 2. Create and activate a virtual environment

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Prepare the data

Download the original dataset from the official UCI source and place `Online Retail.xlsx` in `data/raw/`.

Run the project's data preparation and analysis scripts to generate the processed CSV files required by the dashboard. Check the scripts in `src/data/` and `src/analytics/` for the processing workflow.

### 5. Set up the AI analyst (optional)

Install [Ollama](https://ollama.com/) and download the model:

```bash
ollama pull llama3.2:3b
```

Ensure Ollama is running and the model is available on the machine running the dashboard. The AI analyst will not work on a hosted environment unless that environment can access a compatible Ollama service.

### 6. Start the dashboard

```bash
streamlit run app.py
```

## Data Notes and Limitations

- Revenue values are analytical estimates and should not be interpreted as verified net revenue or profit.
- December 2011 contains partial data through December 9.
- Product and customer rankings may use the full available dataset rather than the selected monthly filter.
- AI-generated explanations are analytical assistance, not proof of causation.
- The AI analyst requires access to the configured Ollama model.
